# สำรองข้อมูล equiplog

สิ่งที่ต้องสำรองมี 2 อย่าง: **ฐานข้อมูล** และ **รูปอุปกรณ์** (โฟลเดอร์ `UPLOAD_DIR`) โค้ดไม่ต้องสำรอง เพราะอยู่ใน GitHub

สคริปต์ `ops/backup.sh` ทำให้ทั้งสองอย่างในครั้งเดียว: `db-<วันเวลา>.sql.gz` กับ `photos-<วันเวลา>.tar.gz` เก็บย้อนหลัง 14 วัน (ปรับได้ด้วย `KEEP_DAYS`) ถ้า dump ไม่สมบูรณ์ สคริปต์จะล้มพร้อมลบไฟล์เสีย ไม่ทิ้งไฟล์ที่ดูเหมือนสำรองแต่ใช้ไม่ได้

> สคริปต์นี้ **ไม่ถูก deploy อัตโนมัติ** (pipeline ส่งเฉพาะไฟล์ build) ต้องคัดลอกขึ้นโฮสต์เองครั้งเดียว

## ตั้งค่าบนโฮสต์ (ทำครั้งเดียว)

1. **อัปโหลดสคริปต์** ด้วย DirectAdmin File Manager ไปที่ `~/ops/backup.sh` (นอกโฟลเดอร์เว็บ) แล้วตั้งสิทธิ์ `700`
2. **สร้างไฟล์ตั้งค่า** `~/.equiplog-backup.env` สิทธิ์ `600` (รหัสผ่านอยู่ในไฟล์นี้ ห้ามส่งในแชต ห้ามใส่ใน git):
   ```
   DB_HOST=localhost
   DB_USER=<ผู้ใช้ DB บนโฮสต์>
   DB_PASSWORD=<รหัสผ่าน DB บนโฮสต์>
   DB_NAME=<ชื่อ DB บนโฮสต์>
   UPLOAD_DIR=/home/<user>/<โฟลเดอร์รูป>      # ค่าเดียวกับ UPLOAD_DIR ของแอป
   BACKUP_DIR=/home/<user>/equiplog-backups   # นอกโฟลเดอร์เว็บ
   ```
   (cron ของ DirectAdmin ไม่เห็นตัวแปร environment ของแอป Node จึงต้องมีไฟล์นี้)
3. **ทดลองรันครั้งแรก** ผ่าน Terminal ของ DirectAdmin (ถ้ามี) หรือผ่าน Cron ชั่วคราว: `bash ~/ops/backup.sh` ควรขึ้น `backup: ok ...` และมีไฟล์ 2 ไฟล์ใน `BACKUP_DIR`
4. **ตั้ง Cron Job** ใน DirectAdmin > Cron Jobs ให้รันทุกวันตอนตีสาม:
   ```
   0 3 * * *   bash $HOME/ops/backup.sh >> $HOME/equiplog-backups/backup.log 2>&1
   ```

## สำคัญ: สำรองในโฮสต์เดียวกันไม่พอ

ไฟล์ใน `BACKUP_DIR` อยู่เครื่องเดียวกับเว็บ ถ้าโฮสต์เสียหรือบัญชีโดนลบ ก็หายพร้อมกัน ควรดึงสำเนาออกมาไว้ที่อื่นด้วย อย่างน้อยอย่างใดอย่างหนึ่ง:

- ดาวน์โหลดโฟลเดอร์ `equiplog-backups` มาเครื่องตัวเองเป็นระยะ (เช่น สัปดาห์ละครั้ง) ผ่าน File Manager หรือ FTP
- ใช้ **Create/Restore Backups** ของ DirectAdmin ถ้าแผนโฮสต์มีให้ และตั้งให้ส่งไปปลายทางภายนอก

## กู้คืน

- **ฐานข้อมูล:** `gzip -dc db-<วันเวลา>.sql.gz | mysql -u <user> -p <ชื่อ DB>` (หรือ Import ผ่าน phpMyAdmin) ควรกู้ลง DB ว่างก่อนเพื่อตรวจ แล้วค่อยสลับใช้งานจริง
- **รูป:** `tar -xzf photos-<วันเวลา>.tar.gz -C <UPLOAD_DIR>`

## สถานะการทดสอบ

สคริปต์ทดสอบแล้วกับ MariaDB ในเครื่อง (dump ได้ครบ 11 ตาราง, tar รูปได้, กรณี DB ไม่มีอยู่จะล้มโดยไม่ทิ้งไฟล์ค้าง) **ยังไม่เคยทดสอบบนโฮสต์จริง และยังไม่ได้ทดสอบขั้นกู้คืน** ควรลองกู้ลง DB ทดสอบหนึ่งครั้งก่อนพึ่งพามัน
